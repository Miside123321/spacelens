# 空间透镜 SpaceLens

Windows 磁盘占用可视化工具——矩形树图 + 横条排行榜 + 缩略图墙，扫描任意盘/文件夹，直观展示谁占了空间。**只读不删，免安装单文件。**

当前版本：**v4.1.2**

## 快速开始

双击 `空间透镜 Web版.exe`，浏览器自动打开界面，选盘/选文件夹 → 开始扫描。

## 功能

- **矩形树图**：SpaceSniffer 式嵌套 Squarified 布局，文件夹带边框层层下钻，双击进入、双击空白返回；面积严格正比占用，层级底色递进，文件按类型着色
- **横条排行榜**：默认首页，子目录/文件按大小降序，彩色圆角横条生长动画，单击逐级下钻，双击文件直接打开
- **缩略图墙**：图片/视频文件夹自动生成封面缩略图（Pillow 直接解码，本地缓存），一眼看到媒体文件夹内容
- **类型分布**：视频/音频/图片/文档/压缩包/应用/系统程序分组占比，扇形图 + 横条图
- **即时搜索**：顶部搜索框内存索引毫秒检索，支持多关键词空格取交集，结果按大小降序
- **磁盘健康度**：S.M.A.R.T. 信息实时显示（健康百分比、温度、通电时间），绿/黄/红预警
- **清理建议**：21 处常见可清理位置分析（临时文件、缓存、回收站等），三档风险分级，只分析不删除
- **软件占用**：读注册表已装软件，合并多目录为一条，显示图标/厂商/占用大小
- **深色/浅色主题**：一键切换，跟随记忆
- **扫描缓存**：7 天内同目标不重扫，开机秒开
- **右键菜单**：在文件管理器中定位、复制路径、打开文件

## 几点说明

- 所有扫描在本机完成，不上传任何数据
- `C:\Windows` 等系统目录部分子项需管理员权限才能读取，普通运行会自动跳过
- 显示为文件逻辑大小之和，与系统"已用空间"可能因硬链接/稀疏文件有少量出入
