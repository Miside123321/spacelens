# 磁盘空间快扫 DiskSurfaceScan

一个本地运行的 Windows 磁盘占用查看小工具：扫描 C 盘或任意盘/文件夹，用直观的矩形树图 + 扇形图显示各目录和文件占了多少空间，并支持按大小、按文件类型两种分类方式。**只做"看"，不做任何删除或清理**。

当前版本：**v4.0.7**（迭代机制：以后每次提改进建议都会递增版本号，更新记录见文末「版本记录」）

## 快速开始

| 方式 | 操作 |
|---|---|
| 推荐 | 双击 **`DiskSurfaceScan.exe`**（免安装，无需 Python） |
| 源码 | 双击 **`启动磁盘快扫.bat`**（需要本机 Python 3.8+） |

打开后：选择盘符或"选择文件夹…" → 点 **开始扫描** → 出图。

## 速度实测（本机 C 盘）

- 全盘 C：**约 11 秒**，扫描 39 万+ 文件、8.3 万目录（8 线程并发，Windows 原生 scandir）
- 单目录（如 Program Files）：1 秒以内

## 功能

- **扫描范围不限 C 盘**：可扫任意盘符，也可只扫某个文件夹
- **矩形树图（SpaceSniffer 式嵌套地图）**：整棵目录树一次铺满画布——文件夹不是一块实心方块，而是"带标题带的地图框"，框内继续切分子项，子项里还是文件夹的就再往下切，一眼看全层级
  - **面积严格正比占用**，squarified 算法保证每块尽量方正（不再出现整屏细条）
  - **帧底色 = 层级**（逐层递进、末位收敛）；**文件色 = 类型**；不再往下细分的文件夹用"内容主类型色"混出底色，既不空白也能看出里面是什么
  - 每层四周内缩 1px，露出的父级底色就是层级网格线
  - 双击文件夹 = 进入下一层（缩放动画），双击根框/空白 = 返回上级，`⬆ 上级` 按钮等价；**贴着文件夹的边框 3px 内点也算点它**，不用去够那 13px 的标题带
  - 悬停看详情；单击选中；右键在文件管理器中打开
  - 绘制预算 4000 块（`SM_MAX_TILES`）：按层分配，预算耗尽时把没画进子块的帧降级成主类型色，**保证屏幕上不出现没有任何信息的白板**
  - 缩放动画期间自动降到 350 块（`SM_ANIM_TILES`）保住帧率，动画结束再用完整预算重绘
- **文件夹排行（横条排行榜，打开软件的默认首页）**：当前目录的子文件夹和文件混在一起按大小从大到小排列；每行 = 名次 + 名称 + 类型/文件数/占比 + 彩色圆角横条 + 条尾大小；切换/进入时横条在 0.8 秒内从左到右级联生长（约 60fps，ease-out）
  - 单击文件夹行 = 进入该文件夹的二级排行榜，可一直点下去；左上角「← 返回上级」回退
  - 名称列加宽，长文件名显示更完整；横条生长动画约 1.1 秒、约 120fps，横条从第一帧起就是全圆角胶囊形
  - 双击文件行 = 用系统默认程序直接打开该文件（视频、图片、文档等）
  - 任意行右键 = 在文件管理器中打开/定位、复制路径；文件还可直接「打开此文件」
  - 超过 100 行后其余小项合并为「其他 N 项」；隐藏/系统文件同样带黄/红点
- **全局深色/浅色主题**：右上角「切换为深色/浅色」一键切换，排行榜、树图、扇形图、列表、标签页、**系统标题栏**全部跟随（Win10 2004+/Win11）；选择会记住（存在 `%LOCALAPPDATA%\DiskSurfaceScan\theme.txt`），下次打开保持
- **顶部即时搜索（Everything 式用法）**：扫描完成后在顶部搜索框输入文件名片段，200ms 防抖、内存索引毫秒级出结果（实测 D 盘 28.9 万个条目，关键词命中数千条也是即时显示）；结果按大小降序、最多显示 1000 条，双击文件夹直接进入它的排行榜、双击文件直接打开、右键在文件管理器中定位；清空搜索框自动回到排行榜。注意：搜索范围是**本次已扫描的内容**，不是 Everything 那种 NTFS 底层实时索引（后者需要管理员权限和卷级读取）
- **磁盘容量条**：扫描完成后磁盘信息行显示「已用/剩余」胶囊容量条（样式同 Windows 驱动器），剩余空间低于 10% 时变红预警，正常为蓝色
- **界面收边**：标签页、面板、滚动条全部去掉多余边框和防滑纹，深色下不再有刺眼白边；滚动条为头尾全圆的小胶囊，整条宽度都是点击/拖动热区，与窗口右边框留有间隔
- **简约滚动条**：所有列表/画布统一为细圆角滚动条，无上下箭头、无防滑纹，悬停时轻微加宽变亮；深色模式下不再有刺眼白框
- **扇形图 + 类型分布**：视频 / 音频 / 图片 / 文档 / 压缩包 / 应用安装 / 系统程序 / 其他，主流扩展名已分组，冷门扩展名自动归入"其他"；内容超出一屏时可滚动（细滚动条 + 鼠标滚轮），条形图为圆角
- **隐藏/系统文件标记**：黄点 = 隐藏文件，红点 = 系统文件；列表与提示中标注"·隐藏/·系统"；并单列统计（状态栏右侧显示隐藏/系统文件各占多少个、多少 GB）——pagefile.sys、hiberfil.sys 这类"隐形大户"一眼可见
- **大文件/大目录排行**：可切换「按文件」（全盘最大 300 个文件）或「按文件夹」（哪些目录占用最大，双击跳转到该目录）
- **避免重复扫描**：同一个盘/文件夹扫过一次后再次选择，直接加载内存缓存（按钮变为「强制重扫」可刷新最新数据）
- **右键菜单**：在矩形树图 / 目录列表 / 大文件排行上右键 → 「在文件管理器中定位（方便删除）」「打开所在文件夹」「复制完整路径」
- 右侧列表显示当前目录各子项的大小、占比、类型；扫描可随时取消

## 几点说明

- **权限**：`C:\Windows`、`System Volume Information` 等系统目录部分子目录需要管理员权限才能读取，普通运行会跳过并计数（状态栏可见"跳过 N 个"）。想扫得更全，可以右键 exe →"以管理员身份运行"。
- **合计口径**：显示的是所有文件逻辑大小之和（与 robocopy/WinDirStat 口径一致）。由于 NTFS 硬链接、稀疏文件等原因，可能和系统"已用空间"有少量出入，属正常现象。
- **不涉及隐私**：所有扫描都在本机完成，不上传任何数据。

## 命令行（可选）

```
DiskSurfaceScan.exe --selftest C:\        # 命令行扫描并输出摘要（用于测试）
DiskSurfaceScan.exe --render C:\ out.png  # 把根目录矩形树图渲染成 PNG
```

## 源码结构

- `disk_surface_scan.py`：单文件源码（纯标准库 tkinter，无第三方依赖），可自行修改后运行
- 引擎：多线程 `os.scandir` 遍历，自底向上汇总文件夹大小；跳过 junction 避免循环计数；通过 NTFS 属性位识别隐藏/系统文件
