# 空间透镜 SpaceLens

Windows 磁盘占用可视化工具：**文件夹排行 + 类型分布 + 清理建议 + 软件占用 + 变化对比 + 内存监测**，
扫描任意盘或文件夹，直接看出谁占了空间。**只读不删：分析过程不修改任何文件，删除与清理都要你确认才执行。**

当前版本：**v4.1.2**

## 快速开始

| 方式 | 操作 |
|---|---|
| 免安装 | 双击 `空间透镜_Web版_v4.1.2.exe`，自动弹出应用窗口 → 选盘/选文件夹 → 开始扫描 |
| 源码运行 | `pip install pillow` 后执行 `python spacelens_web.py`（需要 Python 3.8+） |

界面跑在本地：程序在本机起一个 HTTP 服务，用 Edge/Chrome 的应用窗口打开（`--app` 模式，无地址栏）。
不联网、不上传任何数据。

## 功能

- **文件夹排行**：默认页。子目录与文件按占用降序，彩色横条；单击选中、再点一次或双击进入；列表/方块两种视图
- **缩略图**：图片走 Pillow 解码、视频取首帧（Windows Shell），缩到 256 并压成 JPEG 缓存在本机；文件夹用里面一张图当门面；可一键关掉
- **类型分布**：视频 / 音频 / 图片 / 文档 / 压缩包 / 应用 / 系统程序 分组占比，环形图 + 图例，点扇区可逐级下钻
- **清理建议**：21 处常见可清理位置（临时文件、更新缓存、浏览器缓存、开发包缓存、回收站等），
  按「放心清理 / 看清再清 / 请勿乱动」三档分级；**只分析，不自动删除**
- **软件占用**：读注册表已装软件，反推安装目录后按目录排他归属（一个目录只算给一个软件），
  显示图标 / 厂商 / 分布盘符；右键可按盘打开安装目录，主操作调起软件自己的卸载程序
- **变化对比**：拿最早与最新两份扫描快照比，列出变大 / 新增 / 消失，可逐层下钻，
  每行还能展开看「到底是哪些文件变了」
- **重复文件**：排行页右上角「查重」进入；按大小分组 → 比头尾 64 KB → 整份 SHA-1，
  支持并排比对、自动保留规则、批量清理
- **即时搜索**：从各盘扫描缓存建索引，按相关度排序（名字完全匹配 > 前缀 > 词边界 > 包含 > 仅目录命中），
  支持卡片视图、缩略图开关、搜索词高亮、把「命中文件夹的内容」折叠成一行
- **内存页**：在设置里开启后出现；每秒采样系统内存与进程占用，含磁盘 I/O 波形与进程写入排行
- **主题**：深色 / 浅色 / 跟随系统；设置与偏好保存在本机，重启记得住

## 几点说明

- **只读**：扫描只读取文件名、大小、路径与时间戳，不解析文件内容；不联网、不上传
- **权限**：`C:\Windows` 等目录部分子项需要管理员权限，普通运行会自动跳过（显示的数字会偏小）
- **大小口径**：显示的是文件逻辑大小之和，与资源管理器的"已用空间"可能因硬链接 / 稀疏文件 / 页面文件略有出入
- **本地缓存**：缩略图与扫描结果在 `%LOCALAPPDATA%\DiskSurfaceScan\` 下（缩略图上限 1 GB，按最久未用淘汰）
- **页面文件**：`pagefile.sys` 是 Windows 虚拟内存，大小通常等于物理内存，**不要删**，要调整走系统设置

## 源码结构

| 文件 | 作用 |
|---|---|
| `spacelens_web.py` | 主程序：本地 HTTP 服务、缩略图、清理 / 软件 / 变化 / 内存等页面的数据接口，以及启动浏览器窗口 |
| `disk_surface_scan.py` | 扫描引擎：多线程 `os.scandir` 遍历、自底向上汇总目录大小、快照与差异对比；版本号 `APP_VERSION` 也在这里 |
| `web/index.html` | 整个界面（单文件，含样式与脚本） |
| `web/echarts.min.js` | 类型分布环形图用的图表库（本地文件，不联网加载） |
| `app_icon.ico` | 程序图标 |

## 本机实测

以下是在一台 12 核 / 16 GB / C 盘 129.9 GB 的机器上的实测值，仅作参考：

- **扫描**：全盘 C 约 11 秒（39 万+ 文件、8.3 万目录，8 线程 `os.scandir`）；结果落盘缓存 7 天，开机直接用
- **缩略图**：单张生成 8~84 ms（256 px JPEG 平均 8 KB）；点开目录到首张图可见 125 ms，同目录再次进入 117 ms
- **搜索**：首次查询要为各盘建索引约 4.6 秒，之后单次查询 0.07~0.32 秒（命中 9 万条时）
- **列表渲染**：2885 条搜索结果分帧追加，首屏到下一帧 199 ms
- **帧率**：1360×900 窗口下静态与滚动均为 60 fps（关掉动态背景可再省一截）
